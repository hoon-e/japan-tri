# 일본 소도시 로드트립 랜덤 추천

인천·김포에서 직항으로 접근하기 좋은 일본 권역을 먼저 비교하고, 공개된 후보 중 한 곳을 무작위로 골라 기간별 렌터카 루트를 확인하는 정적 웹 앱입니다.

## 제품 범위

- 로그인 없이 후보 비교 → 랜덤 선택 → 상세 확인 → 기간 전환
- 인천·김포 직항 접근성과 렌터카 소도시 여행 적합성 근거 제공
- 목적지별 사전 작성된 `2박 3일`, `3박 4일` 대표 루트
- 모바일 우선 반응형 UI와 키보드 접근 가능한 기간 탭
- 항공권·숙소·렌터카 예약, 결제, 계정, 저장, 실시간 AI 일정 생성은 제외

> 대표 루트는 MVP용 편집 콘텐츠입니다. 실제 출발 전에는 항공사 운항 일정, 도로 통제, 기상, 렌터카 영업 조건을 다시 확인해야 합니다.

## 로컬 실행

Node.js 20 이상과 Python 3가 필요합니다. 런타임 의존성은 없습니다.

```bash
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. ES 모듈을 사용하므로 `index.html`을 파일로 직접 열지 마세요.

## 검증

```bash
npm test          # 순수 함수, 콘텐츠 무결성, 정적 접근성 계약
npm run typecheck # JavaScript 구문/모듈 검사에 해당하는 무의존성 체크
npm run lint      # 앱과 테스트 파일 정적 구문 검사
npm run check     # 전체 검증
```

테스트는 Node 내장 `node:test`만 사용합니다. 랜덤 함수에는 결정적 RNG를 주입해 결과가 공개 후보군을 벗어나지 않는지 검증합니다.

## 데이터 갱신

목적지와 검수 루트는 `src/data.js`의 정적 구조화 데이터입니다.

1. 인천·김포 출발 지방 공항 직항 여부를 공식 공항 또는 항공사 자료로 재확인합니다.
2. 공항 렌터카 인수 조건과 도시 간 운전 시간을 공식 관광·도로 자료로 확인합니다.
3. 기존 데이터 객체와 같은 필수 필드 및 최소 2개 기간 루트를 작성합니다.
4. `npm run check`로 고유 ID, 필수 필드, 날짜 순서, 루트 참조를 검증합니다.
5. 콘텐츠 근거와 확인일은 저장소의 콘텐츠 출처 문서에 기록합니다.

노선과 도로 상황은 변할 수 있으므로 데이터 변경은 출처 확인과 함께 리뷰합니다.

## 배포

빌드 단계가 없는 정적 사이트입니다. 저장소 루트 전체를 publish directory로 제공하면 됩니다.

- Netlify: `netlify.toml`이 루트 publish와 기본 보안 헤더를 설정합니다.
- GitHub Pages 또는 일반 정적 호스트: 저장소 루트의 `index.html`, `src/`를 그대로 배포합니다.
- 선택적 OpenAI Sites 전달용 Cloudflare Worker 형식 산출물은 `npm run build`로 로컬 생성합니다. 결과물에는 `dist/server/index.js`, `dist/client/`, `dist/.openai/hosting.json`이 포함됩니다. 현재 워크스페이스에서는 Sites 연동이 비활성화되어 실제 저장·배포 검증은 수행하지 않았으며, 프로젝트 ID는 플랫폼 프로비저닝 이후에만 추가할 수 있습니다.

프로덕션 배포는 별도 승인 후 수행합니다.
